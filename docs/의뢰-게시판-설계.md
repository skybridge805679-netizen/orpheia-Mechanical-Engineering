# 길드 의뢰 게시판 설계 v0.1 (2026.11.27)

> 주인님 질문: 「문제만 푸는 게시판이 재미있을까?」 → 아니다. **문제 목록**이 아니라 **작은 이야기 + 손에 잡히는 보상 + 알아서 골라 주는 복습**으로 만든다.
> 이 프로젝트의 목적 = 하기 싫은 공부를 어떻게든 재미있게. 게시판은 그 목적이 가장 쉽게 무너지는 곳이라 따로 설계한다.

## 1. 원칙 세 가지

1. **의뢰 = 의뢰인이 있는 짧은 이야기.** 문제 번호가 아니라 「빵집 할머니의 화덕이 자꾸 식어요」. 문제의 상황을 의뢰인의 사정으로 감싼다. 의뢰 하나 = 2~3분, 문제 1~3개.
2. **보상 = 이 게임을 하는 이유(인물)와 직결.** 점수만 주지 않는다. 오르페이아·히로인·마을이 실제로 달라진다.
3. **고르는 수고를 없앤다.** 「오늘은 뭘 풀지」를 플레이어가 고민하지 않게, 게시판이 복습이 필요한 개념에서 알아서 의뢰를 붙인다.

## 2. 보상 — 「하나만 더」를 만드는 것

| 보상 | 내용 | 왜 끌리나 |
|---|---|---|
| **오르페이아 꾸미기** | 의뢰비(골드)·재료로 오르페이아의 폰 화면 의상·액세서리·배경. 나중에 메이드 몸의 외형 옵션(머리 장식, 메이드복 디자인)으로 이어진다 | 가장 아끼는 인물을 직접 꾸민다. 꾸밀 때마다 오르페이아 반응 대사 |
| **히로인 개별 이야기** | 그 히로인이 낸 의뢰를 몇 건 해결하면 개별 이벤트·CG 해금 | 미연시의 본능: 다음 CG가 보고 싶다 |
| **마을이 바뀐다** | 의뢰를 풀수록 마을 지도가 변한다: 다리가 고쳐지고, 풍차가 돌고, 가로등이 켜지고, 상점이 늘어난다 | 내가 공부한 결과가 눈에 보인다 |
| **공식 카드 등급** | 그 개념 문제를 첫 시도에 맞힐수록 카드가 브론즈 → 실버 → 골드 → 홀로로 바뀐다 | 수집욕 + 「이 개념은 내가 확실히 안다」가 눈에 보인다 |
| **오르페이아와의 잡담** | 일정 건수마다 폰 속 잡담 주제 해금(이세계 음식 품평, 지구 이야기, 질투 등) | 공부와 무관한 순수한 캐릭터 시간 |
| **트루 엔딩 조건** | 메이드 몸 「완성도」에 의뢰 보너스가 더해진다. 본편 진행은 막지 않지만, 완성도 100%여야 특별 기동 엔딩 | 끝까지 갈 이유. 단, 강제는 아니다 |

## 3. 의뢰의 종류 — 같은 문제도 다르게

| 종류 | 형식 | 학습 효과 |
|---|---|---|
| **오늘의 의뢰** (매일 3건) | 헷갈렸던(△·×) 개념 + 오래 안 본 개념에서 자동 출제 | 간격 반복. 플레이어는 그냥 「오늘 의뢰」를 하면 복습이 된다 |
| **연작 의뢰** | 의뢰 3~5건이 이어지는 작은 이야기(화덕 → 굴뚝 → 환기 → 할머니의 감사 파티) | 같은 단원을 이어서 다지며 이야기를 끝까지 보고 싶게 |
| **재의뢰** | 틀렸던 문제가 며칠 뒤 「지난번 그 다리, 또 삐걱거려요」로 돌아온다(같은 개념의 다른 문제) | 오답 복습을 벌이 아닌 이야기로 |
| **현상수배(보스)** | 폭주 골렘·무너지는 탑 등. 여러 개념이 섞인 5문제 | 섞어 풀기(인터리빙). 장 끝 성취감 |
| **라이벌 경쟁** | 마법학원 수석과 같은 의뢰를 두고 주간 해결 수 대결(상대는 NPC) | 가벼운 경쟁심. 지면 라이벌이 으스대고, 이기면 츤데레 반응 |
| **다른 형식** | 같은 문제를 계산서 검수·공식 카드 조립·짝 맞추기·LAB 퍼즐로 | 4지선다만 반복하는 지루함을 깬다 |

## 4. 압박은 빼고, 손은 가볍게

- 시간 제한·벌점·하트 소모 없음. 틀리면 의뢰인이 「괜찮아요, 다시 봐 주실래요?」 + 보충 설명.
- 게시판은 장 클리어 후 열리고, 마을 어디서든(폰) 열 수 있다. 의뢰 1건 = 2~3분.
- 그날 의뢰를 다 하면 오르페이아의 「오늘 수고하셨어요」 + 작은 보너스. 다 안 해도 아무 손해 없음.

## 5. 정할 것

- 보상 중 무엇을 가장 먼저 만들지(오르페이아 꾸미기는 그림이 필요하다 — 그림 정책과 함께 정함)
- 「오늘의 의뢰」를 실제 날짜 기준으로 할지, 게임 안 하루(장 진행) 기준으로 할지
