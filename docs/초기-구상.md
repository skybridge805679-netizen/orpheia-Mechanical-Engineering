# 오르페이아 · 기계공학 — 초기 구상 (v0.1, 2026.11.27)

> **2026.11.27 갱신**: 이야기 틀은 `docs/스토리-설계.md`(이세계 마법공학물), 학습 구조는 `docs/학습-설계.md`로 대체되었다. 이 문서는 경위 기록으로 남긴다.

> 일반기계기사 필기 + 공기업 기계직 전공 문제로 공부하는 학습 미연시.
> 앞선 두 작품을 이어받는다: **연표 오르페이아**(한능검, `orpheia-history`)의 이야기·퀴즈 틀과
> **Orphiey**(철도 관제, `orphiey`)의 「진짜로 만져 보는 실습」 틀.
> 이 문서는 방향을 정하기 위한 초안이다. 정해지지 않은 것은 맨 끝 「정할 것」에 모았다.

## 0. 앞선 두 작품에서 가져올 것 / 바꿔야 할 것

| | 연표 오르페이아(역사) | Orphiey(철도) | 이번 작품(기계) |
|---|---|---|---|
| 배울 것의 성격 | 사실 인식(자료 단서 → 시대) | 절차·판단(무엇을 먼저) | **계산 + 개념**(식을 세우고 숫자를 낸다) |
| 문제 원천 | 한능검 기출 550 + 예상 162 | CTC LAB 시나리오 | 일반기계기사 필기 기출 + 공기업 전공 복원·예상 |
| 핵심 장치 | 다이브 · 묵 배틀 · 가사 고증 검수 · 발매 정산 | 실습 시뮬레이터 · 의미 있는 선택지(bad/why) | **공식 카드 · LAB 실습 · 계산서 검수 · 안전율 정산** |
| 그대로 쓸 것 | `vn.js` 대본 문법, `quiz.js`, 판서, 단서 노트, 되감기, 세이브, 갤러리, 점검 도구(lint·자동 통독) | 「선택지마다 그 선택만의 결말과 교훈」, 장마다 규칙이 하나씩 느는 구성 | |

**가장 큰 차이 = 계산 문제.** 역사는 「알아보면」 풀리지만 기계는 「알아도 식을 잘못 세우거나 단위를 틀리면」 틀린다.
그래서 이번 작품의 새 장치는 전부 **풀이 과정을 게임으로 만드는 것**에 쓴다.

원칙은 앞 작품 그대로 둔다.
- **재미가 먼저다.** 웃기고 설레는 장면이 먼저, 공학 사실은 틀리지 않게 그 안에.
- **알려 준 다음에 풀게 한다.** 문제 앞에서 인물이 그 식이 왜 그렇게 생겼는지 보여 준다.
- **틀린 이유를 보여 준다.** 되감기에서 「어느 단계에서 틀렸는지」(공식 선택 / 단위 / 부호 / 대입)를 짚는다.

## 1. 한 줄 이야기 (안 A — 추천)

> **홀로그램 속에만 있던 오르페이아에게, 주인님이 직접 몸을 설계해 준다.**

- 주인공(플레이어)은 기계공학과 졸업반. 공기업 기계직과 일반기계기사를 동시에 준비 중.
- 오르페이아는 그의 공부를 돕던 전뇌시녀(電脳侍女). 화면 너머에서만 말할 수 있고, 손을 잡을 수 없다.
- 어느 날 학과 창고에서 미완성 **인간형 의체(안드로이드 바디)** 설계 파일과 뼈대가 발견된다. 만들다 만 사람은 사라진 선배.
- 의체를 완성하려면 다섯 과목이 전부 필요하다. 그리고 그 다섯 과목이 바로 **일반기계기사 필기 5과목**이다.

| 과목(기사 필기 순서) | 의체의 부위 | 장의 감정선 |
|---|---|---|
| 1. 재료역학 | **골격** — 프레임·관절축이 하중을 견디는가 | 「제 뼈대, 튼튼하게 만들어 주세요」 첫 공동 작업 |
| 2. 기계열역학 | **심장** — 동력원·냉각, 사이클 효율 | 「열이 나요… 아니, 진짜로요」 체온을 얻는 장 |
| 3. 기계유체역학 | **혈관** — 냉각수·유압 라인의 흐름 | 흐름이 막히면 쓰러진다, 첫 위기 |
| 4. 기계재료 및 유압기기 | **피부와 근육** — 소재·열처리, 관절 액추에이터 | 처음으로 「만질 수 있는」 손가락 |
| 5. 기계제작법 및 기계동력학 | **손끝과 걸음** — 가공 정밀도, 보행·진동 | 첫 걸음, 그리고 손잡기 |
| 종장 | **기동** — 100문항 모의시험 = 기동 시퀀스 | 오르페우스의 시련: 뒤돌아보지 말 것 |

- **이름 모티프**: 오르페우스는 저승에서 에우리디케를 데려오다 뒤돌아봐 잃는다.
  이번엔 주인님이 오르페이아를 「데이터의 저편」에서 현실로 데려온다. 종장의 기동 시퀀스(모의시험) 도중
  「앞 문제로 돌아가지 않기」가 연출상의 시련이 된다(실제로는 시험 끝에 검토 가능 — 연출만).
- **안전율이 곧 점수**: 장마다 부위별 **안전율(S.F.)** 을 정산한다. 첫 시도 정답률이 높을수록 안전율이 오르고,
  1.0 아래면 그 부위가 「파손」 판정 → 보충 장면(재시험) → 다시 정산. 공학 용어가 그대로 게임 수치가 된다.

### 다른 안 (비교용)

- **안 B — 고장 난 거대 기계 정비소**: 낡은 증기 기관차/공장을 되살리는 이야기. 장면 다양성은 좋지만 오르페이아와의 정서적 고리가 약하다.
- **안 C — 공기업 신입 연수원물**: Orphiey처럼 교육생으로 입사해 발전소·플랜트 현장을 돈다. 공기업 문제와 궁합은 최고지만 Orphiey와 너무 겹친다.
- → **안 A를 본편, 안 C의 요소(발전소·플랜트 현장)를 「공기업 편」 외전**으로 붙이는 것을 추천.

## 2. 등장인물 (초안 — 이름 전부 가칭)

| 인물 | 설정 | 재미 담당 |
|---|---|---|
| **주인공** | 기계공학과 졸업반, 취준생. 손재주는 좋은데 공식 암기가 약하다. | 휘말림·츳코미·결정 |
| **오르페이아** | LV.99 인간형 카드, 電脳侍女. 의체가 생길수록 감정 표현이 「물리적」으로 늘어난다(체온·떨림·손). | 해설·질투·설렘 |
| **과목 히로인 5명** | 과목마다 한 명. 그 과목이 「왜」 그런지를 몸으로 아는 사람. 아래 예시. | 장마다 러브코미디 사건 |
| **사라진 선배** | 의체를 설계하다 사라진 사람. 설계 파일 곳곳의 메모가 단서. 정체는 종장에서. | 미스터리 축 |
| **적(가칭) 엔트로피** | 「이유 없이 외운 공식」이 엉겨 생긴 무질서. 의체 곳곳에 **피로 균열**을 낸다. 연표 오르페이아의 「묵」 자리. | 대립·반전 |

과목 히로인 예시(성격만, 외형은 나중에):
- **재료역학** — 구조 동아리 부장. 「버티는 것」에 집착하는 무뚝뚝한 선배. 모어원을 손으로 그린다.
- **기계열역학** — 발전소 견학 안내원 출신 조교. 「되돌릴 수 없는 것」에 약하다(엔트로피와 대칭).
- **기계유체역학** — 수영부 겸 풍동 실험실 막내. 흐름을 몸으로 읽는다.
- **재료·유압** — 대장간 집 딸 + 굴삭기 기사 아버지. 열처리 온도를 색으로 안다.
- **제작법·동역학** — 정밀가공 장인 할아버지 밑에서 자란 공방 소녀. 마이크로미터가 애장품.

> 연표 오르페이아(히로인 36명)처럼 크게 벌리기보다, **과목 히로인 5 + 외전 히로인 몇 명**으로 시작해 늘리는 것을 추천.

## 3. 학습 장치

### 3-1. 문제 형식

| 형식 | 쓰임 | 비고 |
|---|---|---|
| **4지선다(기출 그대로)** | 개념·계산 모두 | 기사 필기 형식 그대로. 점수는 첫 시도만 |
| **풀이 조립** | 계산 문제 앞 단계 | 「어떤 식을 쓸까?」 → 「단위는?」 → 답. 공식 카드를 순서대로 내서 풀이 경로를 만든다 |
| **계산서 검수** | 귀환 장면 | 동료가 쓴 계산서에서 틀린 줄을 찾는다(단위 누락, 지름/반지름 혼동, 게이지압/절대압, kJ↔kW…). 연표 오르페이아 「가사 고증 검수」 자리 |
| **숫자 입력(선택)** | 공기업 편·실기 대비 | 오차 허용 범위로 채점. 본편은 4지선다 위주 |

### 3-2. 공식 카드 (오르페이아 = 카드라는 설정과 맞물림)
- 장마다 공식·개념을 **카드**로 얻는다. 예: `σ = M/Z`, `Z = πd³/32`, `τ = T/Zp`, `η = 1 − T_L/T_H`, `Q = AV`.
- 카드 한 장 = 앞면(식) + 뒷면(「왜 이렇게 생겼나」 한 줄 + 단위 + 자주 하는 실수).
- 계산 문제 앞에서 카드를 골라 풀이 경로를 만든다. 틀린 카드를 내면 그 카드의 뒷면이 「왜 아닌지」를 보여 준다.
- 갤러리 대신 **카드 도감**(과목별 컬렉션). 다 모은 과목은 오르페이아가 직접 요약 노트를 낭독(보너스 보이스 대사).

### 3-3. LAB 실습 (Orphiey CTC LAB 자리)
문제 사이사이에 슬라이더로 직접 만져 보는 작은 시뮬레이션. 「식을 외우기 전에 모양을 본다.」
- 재료역학: 보에 하중을 끌어다 놓으면 **SFD·BMD·처짐**이 실시간으로 그려진다. 좌굴(오일러 하중, 단말 조건).
- 열역학: **P-v / T-s 선도**에서 오토·디젤·랭킨·냉동 사이클을 그려 보고 효율이 어떻게 바뀌나 본다.
- 유체: 관로에서 지름·유속을 바꾸면 **베르누이·연속 방정식**대로 압력이 바뀐다. 무디 선도 읽기.
- 재료: **철-탄소 상태도**에서 온도·탄소량을 찍어 조직(페라이트·펄라이트·오스테나이트…) 맞히기. 유압 회로 기호 조립.
- 동역학: 스프링-질량-댐퍼 진동, 감쇠비에 따른 응답, 기어열 속도비.
- 기술: 빌드 없는 정적 페이지 원칙 유지 → `<canvas>` + 순수 JS. 식 표기는 KaTeX(cdnjs, 버전 고정).

### 3-4. 틀렸을 때
- **되감기**: 고른 보기가 「어떤 실수를 하면 나오는 숫자인지」를 보여 주고 다시 고르게 한다.
  기사 계산 문제의 오답 보기는 대개 실수 패턴(×2, 반지름 대입, 단위 10³)에서 나오므로, 오답 보기마다 실수 이름을 붙인다.
  → Orphiey 원칙 「오답마다 그 선택만의 결말(`bad`)과 교훈(`why`)」을 계산 문제로 옮긴 것.
- **피로 균열 연출**: 틀리면 오르페이아 의체에 균열이 번진다(연표 오르페이아 「의상 버그」 자리). 맞히면 균열이 아문다.

### 3-5. 자동 판서 · 단서 노트
- 연표 오르페이아의 `notesFor`/`preNote`를 그대로 가져와, 문제 앞에 그 단원의 **핵심 식 + 그림**을 칠판으로 펼친다.
- 단서 노트는 「문제에서 읽을 것(주어진 값·구할 값·단위)」 + 「쓸 카드」로 바꾼다.

## 4. 장 구성 (초안)

한 장의 리듬(연표 오르페이아의 리듬을 기계 버전으로):

> 연구실 도입(오늘 만들 부위) → 균열 보고(엔트로피가 밤새 낸 균열 = 그 장의 대표 오개념) →
> 히로인 러브코미디 사건(CG) → 배움 마디(판서·LAB) → 기출 → 균열 봉인 배틀 →
> 계산서 검수(선택지) → **안전율 정산** `@hud` → 부위 장착 CG

| 장 | 제목(가칭) | 범위 | 기출 배정(대략) |
|---|---|---|---|
| 서장 | 화면 너머의 메이드 | 의체 발견, 단위·유효숫자·SI 접두어 | 몸풀기 |
| 1 | 버티는 뼈대 | 재료역학 ① 응력·변형률, 열응력, 비틀림 | 재료역학 |
| 2 | 휘어도 부러지지 않게 | 재료역학 ② 보(SFD·BMD·처짐), 조합응력·모어원, 좌굴 | 재료역학 |
| 3 | 뛰는 심장 | 열역학 ① 1법칙, 이상기체, 상태 변화 | 열역학 |
| 4 | 되돌릴 수 없는 것 | 열역학 ② 2법칙·엔트로피, 사이클(오토·디젤·랭킨·냉동) — 엔트로피의 정체 일부 | 열역학 |
| 5 | 흐르는 피 | 유체 ① 정역학·부력, 베르누이·연속, 운동량 | 유체 |
| 6 | 막힌 혈관 | 유체 ② 관마찰·손실, 차원해석·상사, 경계층 | 유체 |
| 7 | 강철의 피부 | 기계재료: 결정구조, 철-탄소 상태도, 열처리, 재료시험 | 재료·유압 |
| 8 | 힘을 내는 근육 | 유압기기: 펌프·밸브·액추에이터, 회로 | 재료·유압 |
| 9 | 정밀한 손끝 | 기계제작법: 주조·소성가공·용접·절삭·측정 | 제작·동역학 |
| 10 | 첫 걸음 | 기계동력학: 운동학·진동·충돌 | 제작·동역학 |
| 종장 | 기동 시퀀스 | 100문항 모의시험(기사 형식: 과목당 20문항) → 합격 판정 엔딩 | 섞어서 |
| 외전 | 공기업 편 | 기계설계(나사·축·베어링·기어·벨트), 4대역학 고난도, 실기 필답형 계산 | 공기업 복원·예상 |

- **합격 판정**: 기사 필기 기준 그대로 — 과목당 40점 이상 + 평균 60점 이상이면 합격 엔딩,
  과락 과목이 있으면 그 부위가 미완성인 엔딩(그 과목 히로인과의 보충 루트로 이어짐).
- 엔딩 갈래: 히로인 엔딩 5 + 오르페이아 트루 엔딩 + 과락 엔딩들 + 외전(공기업 합격).

## 5. 문제 데이터

- 기사 필기는 과목별 20문항 × 5과목 = 100문항, 4지선다.
- **확인 필요**: 일반기계기사 필기는 CBT 전환(2022년 무렵) 뒤로 회차별 기출이 공개되지 않는다.
  공개 기출(그 이전 회차) + 복원 문제 + 오르페이아 예상 문제로 채워야 한다. 정확한 전환 회차는 자료를 보며 확인한다.
- 공기업 기계직 전공은 대부분 비공개라 **복원 문제 + 출제 경향 기반 예상 문제**가 된다.
- 연표 오르페이아처럼 **한 문항은 이야기 전체에서 한 번만** 낸다. 모자란 자리는 예상 문제로 채운다.
- 계산 문제는 반드시 **숫자를 다시 계산해 정답을 검증**한다(점검 도구에 「정답 재계산」 검사를 넣는다). 역사보다 오답 데이터가 섞이기 쉬운 분야다.
- 데이터 틀(안): `{ n, subj, unit, q, fig, ch:[4], a, cards:[...], traps:{보기번호: "실수 이름"}, exp, src }`.

## 6. 기술 · 에셋

- 빌드 없는 정적 HTML/JS, GitHub Pages. PC 화면 기준(앞 작품과 같음).
- `vn.js`·`quiz.js`·`sfx.js`·`bgm.js`는 연표 오르페이아 판을 가져와 시작 → 대본 문법을 그대로 쓸 수 있다.
- 새로 만들 것: 수식 렌더(KaTeX), 공식 카드 UI, LAB 모듈(`lab/*.js`), 계산서 검수 UI, 안전율 HUD, 정답 재계산 점검.
- 그림: 연표 오르페이아에서 NAI 생성을 멈춘 상태라, **오르페이아 기존 스탠딩 재사용 + 새 그림은 최소한**으로 시작하는 쪽을 추천.
  LAB·판서·카드는 코드로 그리는 그림(SVG/canvas)이라 그림 비용이 거의 없다.
- 음악: Suno(앞 작품과 같은 방식).
