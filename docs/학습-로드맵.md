- 기사 기출 600 = 6회분. **5회분(500)은 1부 각 과목 장에**, **최신 1회분(2026-2, 100)은 2부 시험에 통째로**.
- 과목 순서는 시험지 순서(재료 → 열 → 유체 …)가 아니라 **배우기 쉬운 순서**로 바꿨다:
  재료역학(0부의 힘·모멘트를 바로 씀) → 유체(압력·에너지를 눈에 보이는 물로) → 열역학(가장 추상적이라 유체 뒤) →
  재료·유압(유압은 유체가 먼저 필요) → 제작·동역학(진동은 재료역학의 강성을 씀).
  메이드 몸도 뼈 → 혈관 → 심장 → 근육 → 손끝·걸음 순으로 쌓여 이야기 순서와 맞는다.

## 2부 「기사」 시험
- 2026-2 회차 100문항 통째(과목당 20, 4지선다). 기사 기준 판정: 과목당 40점 이상 + 평균 60점 이상.
- 합격 → 설계도 완성 → 메이드 몸 조립·기동 엔딩. 과락 과목이 있으면 그 과목 히로인과 보충 → 재시험.

## 장 하나의 흐름

1. 앞 장 복습 1~2문제(헷갈렸던 개념 우선)
2. 의뢰 장면(히로인·개그)
3. 개념마다 계단 1~4단(게임 자체 문제)
4. 분해 기출(5단) → 실전 기출(6단)
5. 의뢰 해결 + 길드 승급 심사(그 장 개념 섞어서)
6. 설계도 진척 · 오르페이아 반응
