- 기사 기출 600 = 6회분. **5회분(500)은 1부 각 과목 장에**, **최신 1회분(2026-2, 100)은 2부 시험에 통째로**.

  재료·유압(유압은 유체가 먼저 필요) → 제작·동역학(진동은 재료역학의 강성을 씀).
  메이드 몸도 뼈 → 혈관 → 심장 → 근육 → 손끝·걸음 순으로 쌓여 이야기 순서와 맞는다.

## 610제(공기업) 녹이기 — 2026.11.27

- **세계 안의 자리**: 공기업 = **왕립 공방**(왕국이 운영하는 마도 공학 기관). 610제는 「왕립 공방 입단 시험」 문제로 나온다.
  기사(技師) 자격만 있으면 떠돌이 공학사, 왕립 공방에 들어가야 이세계에 **정착**한다 → 결말(정착)과 바로 이어진다.
- **같은 장, 같은 개념에서 같이 푼다**: 계단 5~6단에서 기사 기출(4지선다)과 공방 문제(5지선다)를 개념별로 섞는다. 화면 표시만 「길드 기사 시험」/「왕립 공방 시험」으로 구분.
- **공기업에만 있는 범위는 장을 더해 본편에 넣는다**:
  - 열전달(전도·대류·복사, 610제 약 23문항) → C5 「열이 빠지는 길」 — 메이드 몸의 냉각.
  - 기계요소 설계(나사·키·축·커플링·베어링·기어·벨트·체인·브레이크·스프링, 610제 약 70문항) → 1부-F 「관절·조립」 3장 — 메이드 몸의 관절과 구동계. 마지막 과목 = 조립 직전 단계라 이야기 순서와 맞는다.
  - 개수로·유체기계 등 → 해당 유체 장에.
  - 단위·압력 기초(파스칼, 절대압/게이지압 등) 쉬운 문항 → 0부 6단 「첫 실전」으로 일부 사용.
- **양 조절**: 기사 600 + 610제 610 = 1210문항. 이야기 진행 중엔 장당 15~20문항만 풀고,
  나머지는 그 장의 **「길드 의뢰 게시판」**(장 클리어 후 열리는 자유 풀이, 등급 점수·설계도 보너스)으로 둔다. 한 문항은 전체에서 한 번만.
- 610제 주제 분류는 레퍼런스 `boost-data.js`의 `TOPIC_OF`(세부 주제 39개)를 1차 기준으로 쓴다.

## 2부 「기사」 시험 → 왕립 공방 입단
- 길드 기사 시험: 2026-2 회차 100문항 통째(과목당 20, 4지선다). 기준: 과목당 40점 이상 + 평균 60점 이상.
- 왕립 공방 입단 시험: 610제 중 한 회차 통째(5지선다).
- 둘 다 붙으면 → 설계도 완성 → 메이드 몸 조립·기동 + 왕립 공방 장인으로 정착하는 엔딩. 과락은 그 과목 히로인과 보충 → 재시험.

## 장 하나의 흐름

1. 앞 장 복습 1~2문제(헷갈렸던 개념 우선)
2. 의뢰 장면(히로인·개그)
3. 개념마다 계단 1~4단(게임 자체 문제)
4. 분해 기출(5단) → 실전 기출(6단)
5. 의뢰 해결 + 길드 승급 심사(그 장 개념 섞어서)
6. 설계도 진척 · 오르페이아 반응
