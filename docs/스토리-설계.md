# 스토리 설계 v0.1 — 「마력 0의 지구인, 공학으로 살아남기」 (2026.11.27)

> 주인님 방향(2026.11.27): 스토리는 **가볍게**. 상철이 스마트폰 하나 들고 마법공학 이세계로 떨어진다.
> 폰에는 자작 AI 오르페이아. 마력이 없는 지구인이라 **공학을 익혀 살아남는다.**
> `docs/초기-구상.md`의 이야기 틀(의체 설계 · 사라진 선배 · 엔트로피)은 이 문서로 대체한다.
> 학습 구조(계단 6단 · 0부 기초 → 과목 → 실전)는 `docs/학습-설계.md` 그대로.

---

## 1. 한 줄

> **마법이 전부인 줄 알았던 세계에서, 마력 0의 지구인이 지렛대 하나로 「무영창 마법사」 소리를 듣기 시작한다.**

## 2. 세계 — 마법공학 세계

- 마력은 이 세계의 **에너지원**일 뿐이다. 마도 기관·골렘·비행선은 마력으로 움직이지만, **부품이 버티는지, 열이 빠지는지, 물이 어디로 흐르는지는 공학이 정한다.**
  → 마법으로 띄운 다리도 보가 약하면 무너지고, 화염 마석 기관도 열효율이 낮으면 과열된다.
- 그래서 이 세계엔 두 갈래 사람이 있다: 감과 주문으로 하는 **마법사**, 계산으로 하는 **공학사**. 마법사들은 공학을 「마력 없는 사람들의 잔재주」로 얕본다.
- 공학사 자격은 **왕립 공학 길드의 「기사(技師)」 시험** — 일반기계기사 5과목 그대로. 마을 사람들은 「기사(騎士)님」으로 잘못 알아듣는다(반복 개그).
- 이세계 단위: 처음엔 「마척」「근」 같은 이 세계 단위가 섞여 있다 → 0-1장 단위 환산의 재료. 길드는 SI와 같은 「표준 단위」를 쓴다(공학이 단위를 통일했다는 설정).

## 3. 인물

| 인물 | 설정 | 재미 담당 |
|---|---|---|
| **상철** | 지구인. 마력 0(상태창에 `MP 0` 표시 개그). 공학 기초 없음 — 플레이어와 같은 출발점. | 츳코미·당황·의외의 손재주 |
| **오르페이아** | 상철의 폰에 설치된 자작 AI. 이세계에선 폰 화면 속에서만 말한다. 카메라로 보고, 계산기로 셈하고, 판서로 가르친다. | 해설·질투(화면 꺼 버리기)·응원 |
| **히로인들** | 과목마다 그 일을 하는 이세계 사람. 아래 예시. | 의뢰·러브코미디 |
| **(선택) 라이벌** | 마법 지상주의 마법학원 수석. 「마력 없는 놈이 무슨」 → 점점 공학에 빠진다. | 대립·츤데레 |

과목 히로인 예시(이름·외형 미정):
- **재료역학** — 다리·성벽을 보는 **드워프 석공 소녀**. 「버티는가」가 입버릇.
- **기계열역학** — 마도 증기 기관을 모는 **화염 마법사**. 불은 잘 다루는데 효율이 엉망이라 늘 과열.
- **기계유체역학** — 수로와 풍차를 관리하는 **엘프 수문지기**.
- **재료·유압** — 대장간 딸 + 골렘 관절을 고치는 정비사.
- **제작법·동역학** — 골렘 기사단의 **골렘 조종사**. 골렘이 걸을 때마다 흔들려서 멀미 중.

## 4. 스마트폰 = 게임 장치

| 폰 기능 | 게임 장치 |
|---|---|
| 오르페이아 앱 | 대화·판서·「풀기 전에, 단서 노트」. 학습 UI를 **폰 화면 모양**으로 띄운다 |
| 계산기 앱 | 공학용 계산기 강좌(레퍼런스 계산기 예제 53개) |
| 카메라 | 오르페이아의 「분석」 — 사물의 치수·하중을 읽어 주는 연출(1단 「느끼기」) |
| 메모장 | 공식 카드 도감 · 개념 이해도(○△×) |
| 배터리 | 가벼운 개그와 장 사이 목표(충전 수단 만들기). **학습에 벌로 쓰지 않는다** |

## 5. 0부 「공구 다루기」 이야기 흐름 (예시)

| 장 | 사건 | 배우는 것 |
|---|---|---|
| 0-1 | 떨어지자마자 시장에서 바가지. 이세계 단위를 표준 단위로 바꿔 사기를 간파 | 단위·접두어·환산 |
| 0-2 | 폰 배터리 18%. 오르페이아가 「남은 시간」을 계산하며 절약 작전 | 식 정리·비례 |
| 0-3 | 우물 도르래 밧줄이 끊어짐. 밧줄 굵기 비교 | 원의 넓이·삼각비 |
| 0-4 | 진흙에 빠진 수레. 몇 명이 어느 방향으로 밀어야 하나 | 힘·벡터·질량과 무게 |
| 0-5 | 마법사도 못 든 바위를 **지렛대**로 들어 올림 → 「무영창 마법?!」 소동, 길드 눈에 띔 | 모멘트·평형 |
| 0-6 | 손으로 돌리는 발전기로 폰 충전 성공. 오르페이아 감격 | 일·에너지·동력 |
| 0-7 | 길드 견습 등록 시험. 그래프 읽기 | 기울기·넓이, 계산기 |

- 1부: 길드 견습으로 과목별 의뢰를 받는다(다리 → 재료역학, 마도 기관 → 열역학, 수로·풍차 → 유체, 대장간·골렘 관절 → 재료·유압, 공방·골렘 보행 → 제작·동역학).
- 길드 등급(F → S)이 학습 진도와 같이 오른다.
- 2부: 「기사」 시험(기출 한 회차 통째) → 합격 엔딩.

## 6. 분위기

- 가볍게. 일상 의뢰 + 이세계 오해 개그 + 러브코미디. 거대한 악역이나 무거운 운명은 두지 않는다.
- 단골 개그: 공학을 마법으로 오해하기 / 「기사(騎士)님!」 / 오르페이아가 히로인에게 질투해서 화면 꺼 버리기 / 배터리 잔량 비명.

## 7. 정할 것

- ~~이 상철이 연표 오르페이아의 그 상철인지~~ → **정함(2026.11.27): 평행세계의 다른 상철.** 연표 오르페이아·Orphiey와 이야기가 이어지지 않는다. 이 세계의 오르페이아도 이 상철이 직접 만든 이 세계의 AI다. 앞 작품 설정(작곡가·윤슬·묵 등)을 대사로 끌어오지 않는다.
- 끝: 지구 귀환 / 이세계 정착 / 고르게 하기. 오르페이아가 폰 밖으로 나오는 길(골렘 몸 등)을 장기 목표로 둘지
- 제목 후보: 「마력 0의 공학사」, 「폰 하나로 이세계 기사(技師)」, 「무영창이 아니라 지렛대입니다」
