# 스토리 설계 v0.1 — 이세계 마법공학물 (2026.11.27)

> 주인님 방향(2026.11.27): **스토리는 가볍게.** 상철이 스마트폰 하나 들고 이세계로 떨어진다.
> 폰에는 자작 AI 오르페이아. 이세계는 마법과 공학이 함께 중요한 마법공학 세계.
> 상철은 마력이 없는 지구인이라 **살아남으려고 공학을 익힌다.**
> `docs/초기-구상.md`의 「의체 설계」 틀은 이 문서로 대체한다(의체는 후반 목표로 남긴다 → §5).
> 학습 구조(계단 6단, 0부 → 1부 → 2부)는 `docs/학습-설계.md` 그대로.

---

## 1. 한 줄

> **마력 0의 지구인, 스마트폰 속 메이드와 함께 공학으로 이세계를 살아남는다.**

톤: 가벼운 이세계 코미디 + 러브코미디. 위기는 「오늘 밤 잘 곳이 없다」「수레가 진흙에 빠졌다」 수준에서 시작한다.
피하는 것: 폰이 마법으로 만능이 되는 전개. **상철은 끝까지 마력 0**이고, 강해지는 건 오직 공학 실력이다.

## 2. 핵심 장치

### 마력(魔力) vs 마력(馬力)
- 이세계 사람들은 태어날 때 마력(魔力)을 잰다. 상철의 측정값은 0 → 길드에서 비웃음.
- 오르페이아: 「괜찮아요, 주인님. 저희는 마력(馬力)을 재면 되니까요.」 — 1 PS = 735.5 W(기사 시험에 실제로 나오는 단위).
- 이 말장난이 작품의 출발점이자 0부 「단위」 장의 첫 장면.

### 스마트폰의 제약 = 공학의 동기
- **배터리**: 처음 목표는 「폰 충전」. 손 발전기 → 물레방아 → 증기 기관으로, 충전 수단이 커질수록 열·유체·동역학을 배운다.
  배터리 %는 HUD의 상징으로만 쓴다(대화할수록 닳는 식의 벌은 주지 않는다).
- **인터넷 없음**: 오르페이아가 아는 것은 폰에 저장된 것뿐. 마침 상철은 떨어지기 전날 **일반기계기사 문제집 PDF와 기출**을 받아 두었다.
  → 레퍼런스 기출 600 · 610제가 「폰 속 문제집」으로 작품 안에 그대로 들어온다.
- **카메라·손전등·계산기**: 소소한 해결 도구이자 개그. 공학용 계산기 앱 = 0-7장 계산기 강좌.

### 기공사 길드 = 기사 시험
- 이세계에는 마도구를 만들고 고치는 **기공사 길드**가 있다. 등급: 견습 → 3급 → 2급 → 1급 기공사.
- 승급 시험 과목이 지구의 일반기계기사 5과목과 똑같다(오르페이아: 「…주인님, 이거 문제집이랑 똑같은데요?」 — 왜 같은지는 후반 떡밥).
- 길드 **의뢰**가 곧 학습 단위: 의뢰 하나 = 개념 하나. 계단 6단과 맞물린다.

| 계단 | 이야기 속 모습 |
|---|---|
| 1 느끼기 | 의뢰 현장(빠진 수레, 새는 우물, 깨진 칼) |
| 2 말로 이해 | 오르페이아·히로인의 설명 |
| 3 식 읽기 | 폰 화면의 「오르페이아 노트」 |
| 4 연습 문제 | 의뢰 해결 계산 |
| 5 분해 기출 | 길드 승급 시험 대비(폰 속 기출을 쪼개서) |
| 6 실전 기출 | 승급 시험 |

## 3. 인물 (전부 가칭)

| 인물 | 설정 | 재미 담당 |
|---|---|---|
| **상철** | 마력 0의 지구인. 기초 부족한 기사 수험생(= 플레이어의 출발점과 같다). 손재주는 있다. | 휘말림·츳코미 |
| **오르페이아** | 상철이 직접 만든 AI. 폰 화면 속 메이드. 이세계 소녀들이 상철에게 붙을 때마다 화면 속에서 삐진다. 몸이 없어 손을 못 잡는 게 은근한 서운함. | 해설·질투·사랑스러움 |
| **과목 히로인** | 과목마다 한 명. 아래는 예시. | 장마다 러브코미디 사건 |
| **라이벌 마도학자** | 마력은 넘치는데 계산을 대충 해서 발명품이 자꾸 터진다. | **계산서 검수**(그의 설계도에서 틀린 줄 찾기)·개그 |

과목 히로인 예시(이세계 원소와 짝):
- **재료역학 · 대지** — 드워프 성벽 기술자. 「버티는 것」에 진심. 상철의 지렛대 계산에 처음으로 감탄해 준 사람.
- **열역학 · 불** — 화룡의 피를 이은 소녀. 체온이 너무 높아 마도구를 다 녹인다 → 냉각·효율 이야기.
- **유체역학 · 물** — 수로 관리인 인어(혹은 물의 정령). 마을 수로가 막히는 사건.
- **재료·유압 · 금속** — 대장간 집 딸. 담금질 온도를 쇠의 색으로 안다.
- **제작법·동역학 · 바람** — 수인 배달부. 빠른 것에 집착 → 속도·진동·회전.
- (공기업 편 외전) 왕립 공방 관리관 — 대형 설비·발전소.

## 4. 흐름 (학습 설계의 3부와 맞춤)

| 부 | 이야기 | 배우는 것 |
|---|---|---|
| 서장 | 떨어짐. 숲에서 폰 하나. 오르페이아 기동. 마력 측정 0. | — |
| **0부 「살아남기」** | 진흙에 빠진 수레(지렛대·모멘트), 길드 가입, 숙소비 벌기, 첫 충전(손 발전기) | 단위·식 정리·삼각비·힘·모멘트·일과 에너지·그래프 |
| **1부 「기공사가 되자」** | 마을 의뢰 → 히로인 사건 → 승급 시험. 충전 수단이 물레방아 → 증기 기관으로 자란다. | 기사 5과목, 과목당 3~4장 |
| **2부 「1급 기공사」** | 길드 1급 시험(기출 한 회차 100문항 통째) | 실전 |

## 5. 후반 떡밥 (가볍게, 필요할 때 꺼낸다)

- **오르페이아의 몸**: 최종 목표는 공학으로 **마도 의체**를 만들어 오르페이아를 폰 밖으로 꺼내는 것. 마력 0의 상철이 만든 몸을 마력으로 움직이는 건 히로인들의 도움.
  초기 구상의 「손을 잡게 되는 결말」을 여기로 옮긴다.
- **왜 길드 시험이 기사 시험과 같은가**: 이 세계의 공학 체계를 세운 사람도 옛날에 떨어진 지구인이었다…는 식으로 가볍게.
- **돌아갈 것인가**: 오르페우스 모티프. 지구로 돌아가는 문 앞에서 「뒤돌아보지 말 것」. 남을지 돌아갈지가 엔딩 갈래.

## 6. 연표 오르페이아와의 관계 (정할 것)

연표 오르페이아에서도 오르페이아는 **상철이 직접 만든 작업 AI**였다. 같은 상철로 이어 갈지(얼굴 없는 작곡가가 이세계로 → 윤슬 카메오 가능),
이름만 같은 새 인물로 갈지 정한다.
