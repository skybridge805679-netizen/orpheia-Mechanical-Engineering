# 학습 설계 v0.2 — 기초부터, 계단으로 (2026.11.27)

> 주인님 방향(2026.11.27): 「기초가 부족해 지금은 기출을 풀 수 없다. 게임에서 기초부터 탄탄하게,
> 스토리를 진행하며 이해하고, 문제를 차근차근 풀어 나가고 싶다.」
> 레퍼런스(기사 600 · 610제)는 **문제만 푸는 곳**이라 그대로는 게임에 맞지 않는다.
> → 기출은 **도착지**로 두고, 거기까지 가는 **계단**을 게임이 직접 만든다.
> `docs/초기-구상.md`의 장 구성(10장)은 이 문서로 대체한다. 이야기 틀(오르페이아 의체)은 그대로.

---

## 1. 원칙

1. **모르는 상태에서 시작한다.** 플레이어가 아는 것은 「중학교 수준 산수」뿐이라고 가정한다. 처음 나오는 기호·단위·용어는 반드시 그 자리에서 풀어 준다.
2. **현상 → 말 → 식 → 숫자.** 식부터 보여 주지 않는다. 손으로 느끼는 현상이 먼저, 그 다음 말로, 그 다음 식, 마지막에 숫자.
3. **한 번에 한 계단.** 문제 하나가 묻는 새 것은 하나뿐이다. 두 가지를 새로 요구하는 문제는 쪼갠다.
4. **틀려도 벌이 아니라 보충.** 초반에는 점수·시간 압박을 두지 않는다. 틀리면 **다른 비유로 다시 설명**하고 비슷한 문제를 한 번 더 준다.
5. **이해했는지 확인하고 넘어간다.** 계단마다 짧은 확인 문제. 막히면 앞 계단으로 돌아가는 길을 열어 둔다.
6. **어제 배운 것을 오늘 꺼낸다.** 장 첫머리에 앞 장 내용을 1~2문제 다시 묻는다(간격 반복).
7. **재미는 그대로.** 강의가 길어지면 VN이 지루해진다. 설명은 LAB(직접 만지기)·일상 소재·인물의 사정으로 나눠 싣는다.

## 2. 계단 6단 — 개념 하나를 배우는 순서

| 단 | 이름 | 하는 일 | 예: 응력 |
|---|---|---|---|
| 1 | **느끼기** | 현상을 보고 만진다(LAB·장면) | 같은 힘으로 실과 밧줄을 당기면 실만 끊어진다 |
| 2 | **말로 이해** | 인물이 비유로 설명 | 「힘을 몇 명이 나눠 드는지」 — 단면 1 mm²마다 걸리는 힘 |
| 3 | **식 읽기** | 기호 하나하나를 말로 읽고 단위를 붙인다 | σ = F / A, N ÷ mm² = MPa |
| 4 | **연습 문제** | 게임이 만든 쉬운 숫자, 한 단계 | 100 N을 10 mm²가 버티면? → 10 MPa |
| 5 | **분해 기출** | 실제 기출을 2~4단계로 쪼개 한 단계씩 | 기사 2024-1 1번(압력 용기 두께)을 단위 맞추기 → 안전계수 → 식 변형 → 대입으로 |
| 6 | **실전 기출** | 원래 4지선다 그대로 | 같은 유형의 다른 회차 기출 |

- 1~4단은 **게임이 직접 만든다**(자체 연습 문제). 5~6단에서 레퍼런스 데이터를 쓴다.
- 레퍼런스 해설의 `steps`가 5단 「분해 기출」의 뼈대가 된다. `mistakes`는 틀렸을 때의 보충 대사, `check`는 확인 문제가 된다.

## 3. 전체 구성 — 3부

### 0부 「공구 다루기」 — 의체를 만들기 전에 (수학·물리 기초)
의체 설계 파일을 열었는데 기호가 하나도 안 읽힌다 → 오르페이아와 공구(수학·단위·물리)부터 익힌다.

| 장 | 내용 | 나중에 쓰이는 곳 |
|---|---|---|
| 0-1 | 단위와 접두어(k·M·G·m·μ), 단위 환산, 10의 거듭제곱 | 모든 과목. 기출 오답의 상당수가 단위 실수 |
| 0-2 | 식 변형(이항), 분수식, 비례·반비례, 제곱·제곱근 | 「t에 대해 정리하기」 |
| 0-3 | 원·원기둥의 넓이·부피, π, 삼각비(sin·cos·tan, 30°·45°·60°) | 단면적, 힘의 분해 |
| 0-4 | 힘과 벡터, 힘의 분해·합성, 질량과 무게(N과 kg) | 정역학 전체 |
| 0-5 | 모멘트(지렛대), 평형(ΣF = 0, ΣM = 0) | 보의 반력, 비틀림 |
| 0-6 | 일·에너지·동력(J·W), 압력(Pa), 온도와 열(K·℃) | 열·유체·동역학 |
| 0-7 | 그래프의 기울기와 넓이(미분·적분의 직관만), 공학용 계산기 | 선도 읽기, 처짐, 일 = 넓이 |

### 1부 「의체 설계」 — 과목별 기초 → 기출 (본편)
과목마다 3~4장. 장 안의 개념 순서는 「앞 개념 없이는 다음을 못 하는」 순서(선수 관계)를 따른다.

| 부위 | 과목 | 개념 순서 |
|---|---|---|
| 골격 | 재료역학 | 응력·변형률 → 후크 법칙·탄성계수 → 푸아송비 → 열응력 → 단면의 성질(I·Z·Ip) → 비틀림 → 보(반력 → SFD·BMD → 굽힘응력 → 처짐) → 조합응력·모어원 → 좌굴 |
| 심장 | 기계열역학 | 계와 상태량 → 일과 열 → 1법칙 → 이상기체(PV = mRT, cp·cv·k) → 4가지 과정 → 2법칙·카르노 → 엔트로피 → 가스 사이클 → 증기(건도)·랭킨 → 냉동·COP |
| 혈관 | 기계유체역학 | 밀도·비중·압력 → 정수압·액주계 → 부력 → 연속 방정식 → 베르누이 → 운동량(분류의 힘) → 점성·레이놀즈수 → 관마찰 손실 → 차원해석·상사 |
| 피부·근육 | 기계재료 및 유압기기 | 결정구조 → 철-탄소 상태도 → 열처리 → 합금강·비철·비금속 → 재료시험 / 파스칼 원리 → 펌프 → 밸브 → 액추에이터 → 회로 기호 |
| 손끝·걸음 | 기계제작법 및 기계동력학 | 주조 → 소성가공 → 용접 → 절삭(V = πDN/1000) → 측정 / 속도·가속도 → 뉴턴 법칙 → 일·에너지·운동량 → 회전 운동 → 진동(ω = √(k/m)) |

- 재료·유압은 계산이 거의 없고 개념 식별 위주(레퍼런스 분석: 개념 114 / 계산 6) → 이 과목만은 연표 오르페이아식 「판서 → 식별 → 짝 맞추기」 비중을 높인다.

### 2부 「기동」 — 실전
- 기출 회차 통째 풀기(100문항, 기사 합격 기준 판정), 약점 과목 보충 루트.
- 외전 「공기업 편」: 610제(5지선다).

## 4. 진도와 복습

- **이해도 표시**: 개념마다 ○(이해) △(헷갈림) ×(모름). 계단 4~6단 결과로 자동 판정. 공식 카드에도 이해도가 붙는다.
- **막히면 돌아가기**: 5단에서 틀리면 그 단계가 기대는 앞 개념(예: 「단위 환산」)으로 바로 가는 「복습 문」을 연다.
- **간격 반복**: △·× 개념은 다음 장 첫머리, 3장 뒤에 다시 나온다.
- **점수 압박은 2부부터**: 0~1부에서는 안전율 정산을 「얼마나 이해했나」 표시로만 쓰고 파손 판정을 하지 않는다.

## 5. 만들어야 할 데이터

- 개념 목록과 선수 관계(그래프) — 약 100~150개 예상.
- 계단 1~4단 자체 문제: 개념마다 연습 문제 3~5개. **정답 재계산 점검 필수**(점검 도구에 넣는다).
- 분해 기출: 기출 해설 `steps`를 단계 문제로 바꾸는 변환(일부 자동 + 손질).
- 레퍼런스에서 그대로 쓸 수 있는 것: 공식 89 · 용어 214 · 통합 개념 32 · 기초 강의(lessons·NEW_LESSONS) · 그림·표.

## 6. 정할 것

- 플레이어(주인님)의 출발점: 어디까지는 편하고 어디부터 막히는지 → 0부의 시작 지점과 속도가 정해진다.
- 0부 분량: 짧게(2~3장) 지나갈지, 위 7장 그대로 갈지.
- 첫 시제품 범위: 0-1장(단위) 한 장을 계단 6단 전부 갖춰 먼저 만들어 보고 느낌을 확인하는 것을 추천.
